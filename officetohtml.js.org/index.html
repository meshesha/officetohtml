Version 2 · TypeScript · no jQuery

Office documents, right in the browser.

One Office-like viewer for Word, PowerPoint, Excel, PDF, images and text files. No server, no plugins, no uploads – files never leave the user's device.

Try the demo Read the docs
npm install @meshesha/officetohtml

Every common format, one API

The file type is detected from the file's content, not just its name. Each format uses the best open-source engine and is shown in a consistent, modern interface.

DOCX

Word documents

Paper-like pages, real image sizes, footnotes, right-to-left paragraphs, zoom, search and printing. Powered by mammoth.js.

docxdocmdotx
PPTX

Presentations

Slide list or slideshow with autoplay, keyboard navigation and full screen. Charts, tables, shapes and media. Powered by PPTXjs v2.

pptxppsxpotx
XLSX

Spreadsheets

Excel-like grid with sheet tabs, formula bar, merged cells, column widths, hidden rows and search. Powered by SheetJS and Handsontable.

PDF files

Selectable text, search with highlights, thumbnails, outline, rotation, hand tool, presentation mode with swipe and pinch zoom. Powered by PDF.js.

A modern image viewer: zoom to the cursor, pinch, pan, rotate, flip, fit and actual size, transparency grid and full screen.

Built for real applications

Version 2 is a complete rewrite of the original jQuery plugin.

🔒 Secure by default

Converted HTML is sanitised, links are checked, PDF scripts never run and file names are always shown as text.

⚡ Loads what it needs

The core is small. PDF.js, mammoth, SheetJS, Handsontable and PPTXjs load only when a file of that type is opened.

🧩 Any framework

Vanilla JS, React, Vue 3, Angular, jQuery (v1-compatible API) and a <office-viewer> Web Component.

🌍 International

UI in English, Hebrew, Arabic, Spanish, French, German, Russian and Chinese, with full right-to-left support.

🌓 Light & dark

Follows the operating system or your setting. Styling uses CSS custom properties that are easy to override.

🖨️ Prints the document

Printing sends only the document to the printer – not your page, toolbar or navigation.

♿ Accessible

Keyboard shortcuts, focus styles, ARIA labels and live regions for status and search results.

🧪 Tested

Unit and DOM tests with Vitest, including regression tests for every security fix.

Get started in a minute

Pick your setup. See the documentation for every option.

import { OfficeViewer } from "@meshesha/officetohtml";

const viewer = new OfficeViewer("#viewer", { theme: "auto" });
await viewer.load("/files/report.docx"); // URL, File, Blob or ArrayBuffer
<div id="viewer" style="height:600px"></div>
<script src="https://cdn.jsdelivr.net/npm/@meshesha/officetohtml@2/dist/officetohtml.umd.js"></script>
<script>
  const viewer = new OfficeToHtml.OfficeViewer("#viewer");
  viewer.load("files/presentation.pptx");
</script>
import { OfficeViewer } from "@meshesha/officetohtml/react";

export function Preview({ file }) {
  return <OfficeViewer src={file} style={{ height: 600 }} onError={(e) => console.error(e)} />;
}
<script setup>
import { OfficeViewer } from "@meshesha/officetohtml/vue";
</script>

<template>
  <OfficeViewer src="/files/budget.xlsx" style="height:600px" @load="onLoad" />
</template>
// main.ts
import { defineOfficeViewerElement } from "@meshesha/officetohtml/angular";
defineOfficeViewerElement();

// component template (add CUSTOM_ELEMENTS_SCHEMA to the component)
// <office-viewer [attr.src]="url" theme="auto" style="height:600px"></office-viewer>
// v1 code keeps working:
$("#resolte-contaniner").officeToHtml({ url: "files/demo.pdf" });

// or the v2 API:
$("#viewer").officeViewer({ src: "files/demo.pdf", theme: "dark" });
